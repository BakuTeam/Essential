# Building Essential

Essential is a PocketMine-MP-based PHP project. For local development, use the PHP build and extensions supported by the PocketMine-MP ecosystem.

1. Install PHP 8.1 or newer and Composer.
2. Install dependencies:

   ```sh
   composer install
   ```

3. Run the source tree with the platform-appropriate launcher:

   ```sh
   ./start.sh
   ```

   On Windows, use `start.cmd` or `start.ps1`.

The `main` branch is the active Essential development branch. See [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request.
