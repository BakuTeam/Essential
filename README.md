# Dummy

**Dummy** — это форк ядра PocketMine-MP с поддержкой версий Minecraft от **1.16+ до самой последней (26.10)**.

## 📌 О проекте

Dummy разработан как специализированное серверное ядро, ориентированное на стабильность и совместимость с современными версиями клиента Minecraft Bedrock Edition.

## ⚙️ Особенности

- Поддержка версий **1.16+ — latest (26.10)**
- Основан на PocketMine-MP
- Оптимизирован для конкретного использования

## 🚫 Использование

> ⚠️ Данное ядро **не предназначено для публичного использования**.

Dummy используется **исключительно** на сервере **Lunarix**.

## 🌐 Сервер

- Название: Lunarix
- Статус: Private
